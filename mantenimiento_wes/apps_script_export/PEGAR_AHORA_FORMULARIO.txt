LISTO PARA MAÑANA — botones Abrir / Cerrar por checklist
=======================================================

Cada checklist (CIR, CPA, SAB) tiene un botón grande:
  [Abrir checklist CIR]  →  [Cerrar checklist CIR]

1) Descargá / abrí este TXT (no uses Doc viejo):
   https://drive.google.com/file/d/1o9fwRGq27iw6nsZ99SIH8s_NlB9ai4xz/view?usp=drivesdk

2) Ctrl+A → Ctrl+C
3) Apps Script → Formulario → Ctrl+A → Ctrl+V → Guardar
4) Nueva versión del /exec oficial
5) Probar: un botón abre solo esa lista; el mismo la cierra
